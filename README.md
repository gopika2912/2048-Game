# 2048 Game - Python with Tkinter 🎮

A simple implementation of the **2048 Game** using **Python** and **Tkinter** for the GUI.

## 📌 Features
- Classic 2048 gameplay
- Smooth animations and tile merging
- Random encouragement messages for motivation
- Sound effects for merges and game over events
- Score tracking

## 🖥️ How to Play
- **Use Arrow Keys (Up, Down, Left, Right) to move tiles.**
- **Combine matching tiles to reach 2048!**
- **Game ends when no more moves are possible.**

## 🎵 Sound Effects
- Merge sound when tiles combine.
- Game over sound when you lose.

## 🔧 Installation & Running the Game
### Prerequisites:
- Python 3.x installed

### Steps:
1. Clone this repository:
   ```sh
   git clone https://github.com/YOUR-USERNAME/2048-Tkinter.git
   cd 2048-Tkinter
   ```
2. Run the game:
   ```sh
   python 2048.py
   ```

## 🛠️ Tech Stack
- **Language:** Python
- **GUI Library:** Tkinter
- **Audio Support:** winsound (for Windows)
